1 · The Problem ↑

In an emergency (fire, earthquake, crush, urban canyons, or inside a building), a crowd of heterogeneous smartphones must find each other. There is no permanent infrastructure, no reliable GPS, no shared absolute reference. Every phone has different sensors, different calibration, different coordinate frames, and different uncertainty.

The core insight: GPS as skeleton, not navigation

GPS is NOT the navigation source. GPS is a coarse, weak global prior — a skeleton that:

  1. Fixes the global gauge (resolves the rigid-transform ambiguity of relative estimation)
  2. Provides a rough initial guess for the optimizer
  3. Anchors the cooperative frame to a global reference when available
  4. Gives weak calibration constraints
  5. Enables gross drift detection (cooperative estimate vs. GPS skeleton divergence)

Precision comes from peer observations — ranging (RSSI/UWB), bearing, displacement, dead reckoning — combined cooperatively across devices.

The central question

How can a population of heterogeneous mobile devices independently calibrate, align, validate, and continuously update their spatial estimates — without a permanently available external spatial authority — and honestly know when they don't know?

2 · State of the Art — Layer Map ↑

The prior art was audited layer-by-layer. Each row names what exists (RES verified) and what is proposed but unverified (EXP).

Layer 1 — GPS Skeleton

GPS as a weak constraint in factor graphs, gauge fixing, GPS-denied bootstrapping, availability transition. Prior art: cooperative positioning with GNSS skeleton exists (surveys, SPAWN family). Gap: mode-level transition when GPS drops — no shared standard.

Layer 2 — Cooperative Estimation

Peer modalities (RSSI, UWB, IMU, bearing), factor-graph formulation, distributed vs. centralized, frame alignment. Prior art: SPAWN, NBP/CoCoA, cooperative WSN localization. Gap: frame alignment without common reference; 2-hop metric tier.

Layer 3 — Calibration

Self-calibration from local sensors; peer-validated calibration (core novelty candidate — using reciprocal inconsistency as the calibration oracle). Prior art: self-calibration exists; peer/reciprocal-flagging does not.

Layer 4 — Uncertainty & Degradation

Uncertainty propagation, graceful degradation (metric→topological→historical→ghost), knowing when you don't know. Gap: no standard degradation hierarchy; continuous σ is false precision — replace with discrete classes.

Layer 5 — Communication

BLE advertisement wire budget (≤31 legacy bytes, ≤23 iOS), partitioned frames, trickle/absorption, partial connectivity, ghost discovery, partition reconciliation. Prior art: BLE relay meshes exist; byte-capped cooperative spatial exchange does not.

Layer 6 — Application

Bare-bones Android/Kotlin app: sensor logging, peer discovery, RSSI ranging, trilateration, GPS skeleton, peer validation, degradation UI. Implemented (P0–P2); experiment program designed but largely [EXP:NOT-RUN].

Honest framing: the mode-ladder (metric/differential/topological/historical/ghost) + ghost-decay + explicit mode-transition events + discrete confidence classes, integrated into a byte-capped BLE emergency mesh, was not found in the confirmatory prior-art pass — this is the survivable integration gap. Each component exists in isolation; the integration is the claim.

Key honesty mechanisms (contributions): (1) discrete confidence classes (CERTAIN/LIKELY/GUESSED/UNKNOWN) replace continuous σ; (2) ghost-decay — nothing deleted, everything decays, contradicting ghosts signal movement; (3) explicit mode-transition events — the UI knows when a signal was lost rather than silently flipping to "unknown"; (4) scope of each claim tagged at observation level.

5 · Novel Contribution (candidate, honest) ↑

  1. Mode-laddered spatial representation — metric / differential / topological / historical / ghost, tagged at observation level. Frame alignment required ONLY in metric tier.
  2. Discrete confidence classes instead of continuous σ — "continuous sigma is false precision"; two bits on the wire, recomputed locally.
  3. Ghost-decay lifecycle — nothing fully expires; it decays to ghost. "Last seen 5 min ago" beats "unknown."
  4. Explicit mode-transition events — every degradation is an observable event; no silent lying.
  5. Direction of Improvement replaces absolute bearing at the local tier — a differential that needs no shared frame, no compass calibration, no 360° spin.

Honest framing: these are architectural contributions (design), not demonstrated results. The formatting above is claim-level honest: peer-validated calibration (§3, L3.2) and all quantitative performance are EXP:NOT-RUN until the 10-experiment program executes — see §6.

6 · Falsifiable Hypothesis & Experiment Program ↑

H: A heterogeneous crowd of smartphones can improve relative spatial reliability through peer-validated cooperative estimation — and degrade more honestly than any single-sensor system — without permanent infrastructure, carrying all spatial context inside a byte-capped BLE budget.

Falsification: if controlled experiments show that (a) independent per-phone estimation ≥ cooperative estimation in mean spatial error, or (b) continuous-σ propagation ≤ discrete classes in error while adding wire cost, or (c) the BLE budget cannot carry the spatial model at the required trickle rate, the hypothesis is weakened or rejected.

On cooperative estimation — SPAWN lineage (Wymeersch et al.)

"We showed cooperative localization works through message passing over factor graphs; the net-factor-graph handles time-varying topology. The hard part is that agents begin with no common reference." — grounded in "Cooperative Localization in Wireless Networks" (IEEE Proc.), RES.

On self-calibration without infrastructure

"Continuous recalibration normally assumes a known frame. In an emergency there is no anchor; calibration itself must come from peer consistency." — synthesis placeholder (position held by L3.x literature), RES (concept) / EXP (novelty unvalidated).

On honest degradation — the "knowing when you don't know" thread

"A navigation system that fabricates a position is worse than one that says 'I don't know.' Emergency systems cannot lie." — synthesis placeholder, RES (principle).
